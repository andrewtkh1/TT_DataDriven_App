Providers

Control (your own connection)

How it works: the browser times a small request to each endpoint every 15 s (round trip incl. TLS, so it is approximate, not a traceroute). Status comes from each provider's public Statuspage API every 60 s. A probe is "slow" when it exceeds 600 ms and 2.5× its recent median. Control probes are independent of the providers, so if they are slow too, the problem is probably on your side. History is kept only in your browser.
